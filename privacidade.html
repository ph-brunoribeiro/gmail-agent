Política de privacidade

Última atualização: 3 de novembro de 2026

O Gmail Agent é uma aplicação de uso pessoal que acede apenas à conta Gmail do seu autor. Esta política explica que dados são usados e como.

Dados acedidos

Com autorização explícita do dono da conta, através da permissão gmail.modify da Google, a aplicação lê os emails recebidos (remetente, assunto e conteúdo), aplica etiquetas, move mensagens para o lixo ou para o spam e cria rascunhos.

Como os dados são usados

  • O conteúdo de cada email novo é enviado à API da Anthropic (Claude) para ser classificado e, quando faz sentido, para redigir um rascunho de resposta. Os dados enviados pela API não são usados para treinar modelos.
  • Para emails importantes, o remetente, o assunto e um resumo curto são enviados como notificação privada ao dono da conta através do Telegram.
  • Num servidor privado na União Europeia fica um registo técnico com os identificadores das mensagens e as ações aplicadas. O conteúdo dos emails não é guardado fora do Gmail.

Partilha

Os dados não são vendidos, nem partilhados para publicidade, nem usados para qualquer fim além de organizar a caixa de correio do próprio dono.

The use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. A partir daí, a aplicação deixa de conseguir aceder à conta.
